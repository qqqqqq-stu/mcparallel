## ⚠️ 已知限制（如实声明）

1. **菜单随门店/时段轮换**：fixtures 录制于宵夜时段（上海店）；早餐单品（麦满分等）不在当前菜单，但营养档案齐全，单品人格优先从营养表推导，不受菜单轮换影响。
2. **价格三路来源**：直接单点在线为 `calculate-price` 实算；离线为菜单价估算（明确标注）；1+1 路径为随心配标价组合。券叠加实付以下单核价为准，不参与最优判定。
3. **营养关联率 50/98**（匹配器 v2：规格族匹配/数量换算/套餐配餐估算）：龙焰等新品与组合 SKU 在官方营养表无对应行，此类单品使用品类基准向量 + 名称规则修正；套餐估算值均在 `estimated` 字段标注口径，绝不冒充官方整餐数据。
4. **口味五维为娱乐画像**：由真实营养/价格数据推导，但映射规则为项目自定义权重，仅供娱乐参考，不构成营养建议。
5. **抽奖概率未知**：官方未公布中奖概率，本项目不猜测、不模拟。
